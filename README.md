# 猫猫大作战

一款猫咪贪吃蛇游戏：吃小鱼、躲避其他猫咪，在大地图中慢慢长大。

## 游戏玩法

- 使用方向键 / WASD 或鼠标转向，空格加速，按 E 使用当前猫咪的技能。
- 猫头碰到边缘或其他猫咪会阵亡；碰到自己的身体没事。阵亡的猫咪会留下小鱼。
- 开始只有奶油橘猫，累计吃鱼解锁其他猫咪；共有 10 只普通猫和 1 只炫彩猫，每只都有自己的技能。
- 单人开始时有 1 只玩家猫和 4 只 AI 猫。游戏进度保存在当前浏览器，可导入或导出。

## 单人游戏

直接在浏览器打开 `index.html`。GitHub Pages 静态网页可运行单人模式。

## 局域网多人对战

多人模式需要一台运行 Node.js 18 或更新版本的电脑来运行游戏服务：

```sh
node server/server.cjs
```

启动后在服务电脑上打开 `http://localhost:3000`，同一局域网的其他电脑使用 `http://服务电脑的局域网IP:3000` 进入，输入名字并点击“联网对战”。大家会进入同一个地图，移动、鱼和碰撞由同一个服务计算。地图上限 80 只猫，真人接近上限时 AI 会让出位置。

服务进程关闭后，对战结束。GitHub Pages 不能运行这个多人服务；如需不同网络的玩家通过互联网一起玩，需要另外部署并保持运行支持 Node.js 的服务器。容量上限为程序设置，真实设备并发效果需按实际网络和服务器条件测试。
